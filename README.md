# Вёрстка сайта Travel Portal 

Проект создан для тренировки навыков адаптивной вёрстки по [шаблону из Figma](https://www.figma.com/design/wTnzxcOBwp3fR1Dkw9PIgc/Travel?node-id=72-28&t=CjG7JOSVFBjSh4XU-0) и загружен в GitHub для удобного отслеживания дальнейших правок.

## О проекте:

**Использовано:** HTML, CSS, JavaScript.

Разработка ведётся в программе Visual Studio Code. Проверка разметки и адаптива производится в браузере Google Chrome с помощью встроенного режима инспектора элементов.

Сайт является адаптивным (или пытается таковым казаться) и меняется в зависимости от разрешения экрана по следующим размерам:

* 1025px *+ *
* 1024px – 769px
* 768px – 391px
* 390px *- *
